# House Price Prediction using Linear Regression

## Overview

This project uses **Linear Regression** to predict house prices based on housing features such as square footage, bedrooms, bathrooms, offers, brick type, and neighborhood.

## Dataset

- **File:** `house-prices (1).csv`
- **Rows:** 128
- **Columns:** 8

### Features

- Home
- Price
- SqFt
- Bedrooms
- Bathrooms
- Offers
- Brick
- Neighborhood

## Technologies Used

- Python
- Pandas
- NumPy
- Scikit-Learn
- Matplotlib
- Seaborn

## Steps

1. Load the house price dataset.
2. Inspect the data and check for missing values.
3. Perform Exploratory Data Analysis (EDA).
4. Create scatter plots and a correlation heatmap.
5. Separate input features (`X`) and target (`y`).
6. Split the data into training and testing sets.
7. Train the Linear Regression model.
8. Predict house prices using the trained model.

## Train-Test Split

- **Training data:** 102 rows
- **Testing data:** 26 rows

## Model

The **Linear Regression** algorithm from Scikit-Learn is used to predict house prices.

## Result

The trained model predicts house prices based on the selected housing features.
